# Control Flow Summary

This section covers the fundamental control flow concepts in Python
and serves as the foundation for all future programming structures.

## Topics Covered
- Decision making with `if / elif / else`
- Comparison operators
- Logical operators
- Nested conditions
- Guard conditions
- `match-case` statements (Python 3.10+)

## Structure Overview
- **Example files** introduce each concept in isolation.
- **Practice files** focus on repetition and basic problem-solving.
- **Mini projects** combine multiple concepts to simulate real-life scenarios.

Guard conditions and match-case statements are practiced primarily
through examples and mini projects to avoid unnecessary repetition.

## Learning Path
This folder is part of a gradual, numbered learning path.
After mastering control flow, the next step is looping structures
(`while`, `for`, and nested loops).
